# Hive Bloom

Puzzle original pe fagure hexagonal (37 celule). Pui piesa curentă într-o celulă goală; 3+ piese egale care se ating se unesc în nivelul următor, în lanț:
🌱 → 🍀 → 🌷 → 🌼 → 🌻 → 🍯 → 🐝 → 👑 → 🌟 (trei stele = floare de aur, curăță vecinii).
De la mutarea 25 apar pietre 🪨, sparte de orice unire alături. Unelte: Schimbă (gratuit), Ciocan (15 🍯), „Fă loc” la final (25 🍯, o dată).
Stupul zilei (seed pe dată), 6 teme cosmetice, RO/EN/RU, mobil + desktop + tastatură, sunet sintetizat, fără reclame.

- Teste: `CHROME_PATH=/opt/pw-browsers/chromium node hive/tests/run.js`
- Capturi și coperți: `node hive/tools/shots.js` → `hive/launch/`
